# Übersetzungen (i18n)

Englisch ist die Grundsprache. Die Sprache von Etude ist immer die Systemsprache
(`~/.config/locale.conf`, `/etc/locale.conf`, sonst `$LANG`) – ändert sie sich, wechselt Etude
sofort. Gibt es für die Sprache keine Übersetzung, gilt Englisch (je Text).
Wie bei Omarchy liegen alle Texte gesammelt in `default/i18n/<sprache>/<bereich>.json`
(Paket: `/usr/share/etude/default/i18n`) – eine neue Sprache ist damit genau ein neuer Ordner.

## Aufbau

```
qml/Etude/Ui/I18n.qml              Systemsprache bestimmen, I18n.locale, gemeinsame Texte
qml/Etude/Ui/Translations.qml      Katalog eines Bereichs laden
qml/Etude/Ui/Plural.js             Mehrzahl-Regeln
default/i18n/en/ui.json            gemeinsame Wörter von Etude.Ui: common.cancel, …
default/i18n/en/settings.json      Texte einer App (settings, files, taskmanager)
default/i18n/en/bar.json           Texte eines Shell-Moduls (bar, startmenu, notifications …)
default/i18n/en/lock.json          Texte eines QML-Moduls (lock, menus, services)
default/i18n/de/…                  dieselben Dateien auf Deutsch
```

Der Bereich ist der Name der App bzw. des Moduls in Kleinbuchstaben. `en/` ist die Grundlage
und muss immer vollständig sein.

Ein Katalog ist flach. Schlüssel: `<bereich>.<name>` in camelCase. Werte sind Text oder – für
Zahlen – ein Mehrzahl-Objekt nach CLDR (`one`, `few`, `many`, `other`; `other` immer):

```json
{
  "files.newFolder": "New folder",
  "files.selected": "%1 selected",
  "files.items": { "one": "%1 item", "other": "%1 items" }
}
```

Ordnername = Sprachcode: `de/`, `nl/`, für Regionen `pt-BR/`. Fehlt ein Text, gilt die
Grundsprache (`de_AT` → `de-AT/` → `de/`), dann Englisch, dann der Schlüssel.

## Im Code

```qml
import Etude.Ui

Translations { id: tr; domain: "files" }                         // default/i18n/<sprache>/files.json

Text { text: tr.t("files.newFolder") }
Text { text: tr.t("files.selected").arg(name) }
Text { text: tr.tn("files.items", n).arg(I18n.formatNumber(n)) }
Button { text: I18n.t("common.cancel") }                          // gemeinsame Texte
Text { text: date.toLocaleDateString(I18n.locale, Locale.LongFormat) }
```

Keine Texte zusammensetzen (`n + " Elemente"`), sondern Platzhalter benutzen – die Reihenfolge
der Wörter ist nicht in jeder Sprache gleich. Sprachwechsel wirken sofort, ohne Neustart.

In Shell-Skripten: `etude-i18n -D files [--count n] key werte…`

Eigenständige Apps, die nur `etude-ui` benutzen, bringen ihre Texte selbst mit – als Ordner mit
`en.json`, `de.json` …: `Translations { directory: Qt.resolvedUrl("i18n") }` bzw.
`etude-i18n -d <ordner> key`.

## Prüfen

```sh
python3 scripts/i18n-check.py              # Fehler und fehlende Übersetzungen
python3 scripts/i18n-check.py --literals   # Texte, die noch fest im Code stehen
python3 scripts/i18n-check.py --verbose    # welche Schlüssel fehlen
```

## Neue Sprache

1. Ordner `default/i18n/<code>/` anlegen und die Dateien aus `en/` übersetzen (es reicht, was
   schon übersetzt ist – der Rest bleibt englisch)
2. braucht die Sprache andere Mehrzahl-Regeln: `qml/Etude/Ui/Plural.js` ergänzen

Eine Liste der Sprachen gibt es nicht: Datum, Zahlen und Wochentage kommen aus der Systemsprache
(`Qt.locale`), die Texte aus den Katalogen, die es gibt.
